# МАГНИТ

Новый самостоятельный проект Артура. Python 3.10+, только стандартная библиотека.

Работает в личных чатах @MagnitWaveBot. /start, /crypto, /news, /music запрос,
/settings, /ai вопрос, /privacy, /forget. Кнопки используют те же обработчики.

Котировки: CoinGecko, кеш 90 секунд, отметка времени источника.
Новости: RSS BBC Russian и ForkLog, кеш 3 минуты, ссылки и даты публикации.
Музыка: поиск iTunes, ссылки на Apple Music. Аудиофайлы не копируются.
AI: Responses API, опциональный отдельный ключ OpenAI. 10 запросов на человека
в сутки UTC, до 2000 символов на запрос. API оплачивается отдельно от ChatGPT.
Настройки хранятся в SQLite. Тексты сообщений и ключи не попадают в git и логи.
Один пользователь может запускать запрос раз в 2 секунды.

## Установка

MAGNIT_INSTALL.cmd внутри ZIP. Требуется Windows с PowerShell 5.1+, встроенным
OpenSSH и ключом %USERPROFILE%\.ssh\peretosh_bot.key. SSH-доступ ubuntu к Oracle
129.213.23.39 должен уже работать. Неизвестный ключ сервера SSH потребует
обычного подтверждения в консоли. Установщик не отключает проверку ключа.

Токен вводится в скрытом поле. Проверяется имя MagnitWaveBot. AI подключается
по желанию, отдельным скрытым полем. Пустой токен при повторном запуске сохраняет
текущий серверный токен. Отказ от добавления ключа AI сохраняет текущий ключ.

На Oracle нужны git, python3 (3.10+) с sqlite3, systemd и sudo без пароля у ubuntu.
Python-пакеты и дополнительные зависимости не устанавливаются. Исходники
из встроенного git bundle помещаются в отдельный репозиторий magnit.git.
Существующие сервисы и Peretosh не меняются.

/opt/magnit/releases/<commit> и current, /etc/magnit/config.json (root:magnit 0640),
/var/lib/magnit/magnit.sqlite3, systemd magnit.service, localhost:8769/health.
Бэкапы: /opt/magnit/backups, включая конфигурацию с секретами (root 0700).
Локальная копия исходников: Документы\MagnitMain.bundle. Секретов в ней нет.

Каждый запуск делает бэкап, прогоняет тесты и секрет-сканер, проверяет токен,
запускает сервис, ждёт успешного long polling и сверяет ревизию, ставит deployed.
Отдельный post-receive хук включает автоматическую выкладку push в main.
Неуспешный хук не отменяет push: deployed остаётся последней успешной версией.
При ошибке запуска восстанавливаются предыдущий релиз и конфигурация.
Снимок SQLite делается через online backup. Рабочая БД при откате не заменяется.
При существующем webhook установка останавливается без его удаления.

## Проверки

python3 -m unittest -v
python3 deploy/scan.py .

HTTP-харнесс запускает отдельный процесс бота, отдаёт входящие Telegram updates,
проверяет исходящие sendMessage, RSS, котировки, музыку и сохранённый offset.
Тестовые данные не являются запросом к Telegram или проверкой живых источников.
Окончательная проверка: отправить /start настоящему боту после установки.

Откат: git revert <commit>, затем push main в /home/ubuntu/git/magnit.git.
При первом релизе для остановки: sudo systemctl disable --now magnit.
