Use it

One file to run

Download MAGNIT_START.zip
  1. Extract the ZIP and double-click MAGNIT_START.cmd.
  2. The installer opens BotFather. Copy the token for @MagnitWaveBot and paste it into the installer's hidden prompt. Do not send it in chat.
  3. Leave the window open. The installer runs checks, saves backups, installs the service, and requires a matching deployed tag before reporting the installed release.
  4. When the bot opens in Telegram, send /start. The window checks for a newly confirmed response. LIVE_REPLY_OK means the bot successfully sent a new reply after the check began. In a shared bot, this counter can include another user's reply.

Three Telegram checks

  1. /start displays the MAGNIT DEMO menu.
  2. Open a demo position, then view portfolio and activity.
  3. Press the Russian/English button and confirm the menu language changes.

If the installer reports only that the release is running, but no live reply was confirmed within 90 seconds, send /start again. The report distinguishes that state from a checked reply.
